# Drafting Overlay Preference

The preferred motion language is the homepage "Our first step is listening" drafting overlay.

Use these names when requesting it again:

- `DraftingMotionLayer`
- animated drafting overlay
- scroll-tied ruler and grid
- blueprint grid/ruler animation
- technical drafting marks

The client likes this because it feels architectural, precise, construction-specific, and premium. When adding it elsewhere, keep it restrained: it should support the content like a plan sheet or measurement layer, not become a decorative background on every section.
