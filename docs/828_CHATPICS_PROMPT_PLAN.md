# 828 Chatpics Prompt Plan

Use these prompts to create assets, then place the generated files in `chatpics/`.

## Global Visual Theme

Every prompt below already includes this theme:

`Cinematic premium residential construction brand for 828 Construction in Torrance and the South Bay, California. Refined builder-led vision: active listening, building science, craftsmanship, durability, clarity, and client trust. Modern high-end residential materials, natural daylight or warm dusk practical lighting, black/maroon/copper brand accents, sharp editorial composition, realistic textures, no cartoon style, no generic stock-photo feeling, no fake text, no logos unless requested, no people posing at camera. Professional, alive, dimensional, ready for a luxury contractor website.`

## Current Audit

Screenshots were captured under `.claude-work/image-prompt-audit/`.

Main issues found:

- Home hero has a floating grey house outline that looks placeholder and should be removed or replaced with a refined construction detail layer.
- Home is too black between sections; it needs photographed material details and transparent cutout objects to make the motion feel alive.
- About hero is professional, but the following white story area feels plain without a founder/workbench detail image.
- Services page is strong structurally, but the hero framing-wall image feels cold and empty; it needs more premium craft and clearer service-specific visual cues.
- Service detail pages are too similar: black text panel plus one image. ADU, remediation, and consulting each need their own visual language.
- Portfolio/projects/process all route to the same portfolio experience. It needs better hero imagery and more cinematic project support assets, not more abstract linework.
- Contact hero is decent, but it reads like a moody front door instead of a direct invitation from a trusted local contractor.
